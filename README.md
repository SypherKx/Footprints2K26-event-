## ⚡ About The Project

**Footprints 2K26** is scheduled for **February 16, 2026**. This premium responsive web platform delivers an immersive experience for participants to explore 14 diverse sports events, meet the coordinators, view past galleries, and seamlessly register through a secure, gender-based portal.

---

## ✨ Core Features

### 🎮 Immersive User Experience
*   **Hero Section** – Dynamic full-screen video background with an interactive countdown timer.
*   **Smooth Animations** – Powered by `GSAP` and `Framer Motion` for buttery-smooth scrolling and transitions.
*   **Modern Aesthetics** – A sleek dark theme with vibrant, energetic accent colors tailored for a sports vibe.

### 🏆 Event Management
*   **Event Showcase** – Interactive 3D tilt cards showcasing 14 distinct sports events.
*   **Smart Filtering** – Day-wise event filtering and comprehensive event detail modals.
*   **Registration Portal** – Secure, gender-specific registration links utilizing deep-linking.

### 🛠️ Advanced Tooling
*   **QR Code Generation** – Instant QR codes for digital event tickets.
*   **Real-time Database** – Seamless `Firebase` integration for managing operations.
*   **Performance Tracking** – Integrated `Vercel Analytics` for user behavior tracking.

## 🚀 Quick Start

Follow these steps to set up the project locally on your machine.

### Prerequisites

Ensure you have the following installed:
*   [Node.js](https://nodejs.org/) (v16.x or newer)
*   npm (v8.x or newer) or [Yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/SypherKx/Footprints2K26-event-.git
   cd Footprints2K26-event-
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm start
   ```
   > The app will be available at `http://localhost:3000`

## 🛠️ Technology Stack

*   **Core UI:** React 18, React Router v6
*   **Styling Engine:** TailwindCSS v4, SASS/SCSS Modules
*   **Motion & Animation:** GSAP, Framer Motion, React Parallax Tilt
*   **Backend & Cloud:** Firebase
*   **Media Processing:** Fluent-FFmpeg, Sharp
*   **Analytics:** Vercel Analytics
